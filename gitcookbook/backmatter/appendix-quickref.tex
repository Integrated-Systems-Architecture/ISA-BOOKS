\section*{The five traps to remember}

\begin{enumerate}
  \item Editing a file does not stage it, and staging does not commit
        it -- three separate steps.
  \item \code{git add .} stages everything, junk included; keep a
        \file{.gitignore} from the first commit.
  \item \code{reset --hard} discards work with no confirmation; use
        \code{revert} on anything already pushed.
  \item Never force-push a branch someone else is also working on.
  \item One pull request, one concern.
\end{enumerate}
